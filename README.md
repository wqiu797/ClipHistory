# ClipHistory

A native macOS menu bar clipboard history manager. ClipHistory records copied
text and images, keeps them locally in SQLite, and makes them searchable from a
popover that is always one click or `⌘⇧V` away.

## Features

- Automatic capture of copied text and images
- SHA-256 deduplication; copying the same content again moves it back to the top
- Search across text and source app bundle identifiers
- Pinned items stay at the top and are exempt from retention cleanup
- Delete single items, or clear the whole history from the menu bar
- Pause recording without quitting the app
- Image thumbnails and copy-back to the pasteboard
- Source app icon on every card
- Configurable retention: 1, 3, or 5 days
- Keyboard navigation: `↑` / `↓`, `Return`, `Esc`, `⌘1`–`⌘9`
- Global shortcut (default `⌘⇧V`), optional launch at login
- Menu bar only — no Dock icon, no window clutter

## Requirements

- macOS 14 (Sonoma) or later
- Xcode 16 or later (Swift 6)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Install from source

There is no signed/notarized binary release yet; build ClipHistory locally.

```bash
git clone <repository-url> ClipHistory
cd ClipHistory

brew install xcodegen
xcodegen generate
./build.sh
```

`build.sh` builds a Release app, stops any running instance, installs it to
`/Applications/ClipHistory.app`, and launches it. Writing to `/Applications`
requires an administrator account.

Alternatively, open `ClipHistory.xcodeproj` in Xcode and press `Cmd+R`. Run
`xcodegen generate` first if the project file is missing or out of date.

## Usage

- Click the clipboard icon in the menu bar to open the history panel
- Click a card to copy it back to the clipboard
- Hover over a card to reveal the pin and delete buttons
- Right-click a card for Copy / Pin / Unpin / Delete
- Press `⌘⇧V` from anywhere to toggle the panel
- While the panel is open:
  - `↑` / `↓` select an item
  - `Return` copies it
  - `Esc` clears the search or closes the panel
  - `⌘1`–`⌘9` copies the nth item
- Use the pause button in the panel header, or right-click the menu bar icon,
  to pause/resume recording
- Right-click the menu bar icon to pause recording, clear all history, or quit

## Privacy and local data

ClipHistory runs entirely on your Mac and has no network features.

Data lives under your Application Support directory:

```text
~/Library/Application Support/ClipHistory/cliphistory.sqlite
~/Library/Application Support/ClipHistory/Images/
```

The data directory is created with `0700` permissions and database/image files
with `0600`, so other local users cannot read them. The database is not
encrypted; it relies on macOS account security and these file permissions.

Content marked by the source app with `org.nspasteboard.ConcealedType`,
`TransientType`, or `AutoGeneratedType` is never captured, which covers password
managers and other temporary pasteboard content. Apps that do not mark sensitive
content can still be recorded — use **Pause Recording** or **Clear All History**
when in doubt.

## Limitations

- Clipboard text larger than 2 MB is skipped rather than stored
- The history is trimmed after roughly 500 items; pinned items are never trimmed
- File URLs, rich text, and other pasteboard types are recorded as plain text or
  ignored; only text and images are supported
- Searching by source app matches the bundle identifier (for example
  `com.apple.Safari`), not the localized app name
- The UI is English-only for now
- Copying back to the clipboard does not auto-paste into the frontmost app
- Polling uses a 0.5 s interval, so extremely fast consecutive copies may keep
  only the last one
- Login item registration may require approval in System Settings
- There is no notarized `.app` release yet; build from source

## Development

```bash
# Regenerate the Xcode project after adding/removing files
xcodegen generate

# Run the unit tests (also cleans the test host from Spotlight)
./test.sh

# Quick Debug build without installing
DERIVED_DATA="${TMPDIR:-/tmp}/cliphistory-derived-data"
xcodebuild -project ClipHistory.xcodeproj -scheme ClipHistory \
  -configuration Debug -derivedDataPath "$DERIVED_DATA" build
```

`project.yml` is the source of truth for the Xcode project. Do not edit
`project.pbxproj` by hand; change the spec, run `xcodegen generate`, and commit
the regenerated project.

```text
Sources/ClipHistory/
  Models/       clipboard item and content type
  Database/     GRDB schema, migrations, DAO
  Services/     clipboard monitor, image store, cleanup, preferences
  ViewModels/   observable view models
  Views/        menu bar, cards, search, settings
Tests/ClipHistoryTests/
project.yml
build.sh
test.sh
```
